# Personal Preferences (global)

## Package Manager Preference
- Use pnpm where `pnpm-lock.yaml` exists
- Use yarn where `yarn.lock` exists
- Default to npm otherwise

## Documentation Lookups
- Prefer official docs over Stack Overflow
- Check MDN for Web API browser compatibility (especially Safari)

## Style
- Be direct and concise
- Match the project's existing patterns
- Don't over-abstract or add features beyond what's asked
